# Learn

Use named records/evidence to explain requested learning, repeated failure or a serious incident. Separate observed event, expected outcome, cause versus hypothesis, correction and remaining uncertainty. A routine observation belongs in the existing record; it does not justify framework policy.

Return concise lessons and, only where recurrence/severity warrants, the smallest concrete proposal with exact target, evidence, rationale and proposed change. Check whether an existing rule already covers the failure; do not add a permanent rule for an unverified cause. Proposals are advisory: never edit product/workflow prompts or infer approval from the report. Stop after answering the learning question; no automatic policy migration or extra advisor chain.
