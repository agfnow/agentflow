# Spike

Test one named technical unknown as a falsifiable claim with an observable pass condition. Use the smallest authorized experiment in the host-declared scratch path under its producing Ask's artifacts; protect product files and avoid reusable abstractions. A probe needing new access, spending, destructive changes or external writes awaits that authority; continue independent work.

Record actual commands, relevant versions/environment, observed output/errors, verdict (resolved, inconclusive or could not run) and the strongest limit on generalization. An unrun experiment proves nothing. State only evidence-backed implications for the contract, leaving product choices to the owner. Stop when answered or blocked by missing evidence; do not build the feature inside the spike.
