# Codewalk

Map only the named change surface and necessary dependencies: entry points, data/control flow, public interfaces, local conventions, likely edit locations and verification seams. For broad unfamiliar scope, start with architecture; deepen only implicated paths.

Within the affected UI paths, check authorized sources for shared design systems, component catalogs (e.g. Storybook), Figma and their code mappings. For a verified local reimplementation, warn with both source references, a reusable component or style and the observed variant or behavior fit or gap. Label uncertain matches as candidates. Record evidenced intentional exceptions without warning. Report relevant sources you could not check.

Stay read-only. Verify paths and supported commands against actual source/manifests/CI; label commands run or not run. Run only an authorized non-mutating probe for a named fact reading cannot settle. Return checked revision/files, facts versus inferences, conflicts, likely edit paths/checks and unexamined areas. Stop once implementation locations/dependencies are sufficiently known; do not turn a map into a whole-repository tour or a product decision.
