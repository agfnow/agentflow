# aglite 0.3.1

Before authoring chat, Replies, reports or user documentation, read and apply [writing guidance](references/writing.md): make human-facing writing easy to read and quick to scan with short, single-concept prose paragraphs or list items, preserving comprehension; machine-only prompts may be aggressively compressed without losing requirements or safeguards. ## Looper task execution

For `prepare-tasks <request>`, `run-tasks [run-root]` or `handle-tasks <request>`, read [looper](references/looper.md) before preparation, execution or recovery. `prepare-tasks` derives groups with optional earlier-group dependencies and prepares the Current-linked `queue.json`, `planned/request.md` and `planned/group-NNN.md`, then stops; `run-tasks` executes that queue (explicit root overrides); `handle-tasks` combines both. Preserve ordinary workflow/review/executor settings in fresh sequential task sessions, with group-isolated records. Only this feature permits the scoped Node.js coordinator/`agf` launcher. `ag.json` alone owns editable routes/model settings/limits; queues retain instructions, progress and immutable attempt evidence. Native dispatch requires the live host and result mailbox; absent host blocks native work without CLI substitution. CLI task sessions support Codex/Claude. One coordinator owns queue writes and target-wide serial integration; clean checked merges add no agents, while repair retains independent review/acceptance. No group/wave/final gates or separate promotion. Owner-only decisions, ordinary shared-record ownership and no-hook/no-publisher boundaries remain; no cleanup, push or release authority follows.

## Task modes
